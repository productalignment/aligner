# FL-012 Try options in branches
- jobs: JB-008

## Steps
- FS-095: [start-end] For each option, start a new branch from Aligner's branch menu
- FS-096: [user-action] Spec the option there, or have your coding agent, on that branch, draft its flow and sketch its screens
- FS-097: [user-action] Open the option's branch in Aligner, review them, and draw your changes over the sketches
  - screen: SC-009
- FS-098: [system-action] Commit, and pick the branch in your coding agent: a model, even a cheaper one, builds the option and updates its product context
- FS-099: [user-action] Deploy the branch and measure it
- FS-100: [user-decision] Does it win?
- FS-101: [start-end] Merge it: its code and product context reach main together
- FS-102: [start-end] Drop the branch: nothing to clean up
